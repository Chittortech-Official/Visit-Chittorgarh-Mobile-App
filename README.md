# Chittorgarh Fort: Travel & Audio Guide 🏰

Official Android Application for [VisitChittorgarh.in](https://www.visitchittorgarh.in/), verified and published by **ChittorTech**.

## 📱 Features
- **Live Sync Architecture:** Real-time sync with `https://www.visitchittorgarh.in/` without requiring Play Store app updates for content, blogs, or rates changes.
- **Native Royal Splash Screen:** Custom heritage themed launch screen with Chittorgarh Fort emblem.
- **Offline Fallback & Helplines:** Offline detection with instant emergency helpline access for tourists atop the 700-acre fort.
- **Native Deep Link Interception:** Direct integration for WhatsApp bookings, phone dialer calls, and Google Maps GPS navigation.
- **Swipe-To-Refresh:** Built-in Material pull-to-refresh with ChittorTech amber styling.

## 🛠️ Project Setup in Android Studio
1. Open **Android Studio**.
2. Select **Open** and choose this repository directory (`Visit-Chittorgarh-Mobile-App`).
3. Android Studio will automatically detect the Gradle files and prompt **Sync Project with Gradle Files**.
4. To build release bundle:
   ```bash
   ./gradlew bundleRelease
   ```

## 📦 Package Details
- **Application ID:** `in.visitchittorgarh.fort.tour.guide`
- **Target SDK:** 36 (Android 15+)
- **Min SDK:** 24 (Android 7.0+)
- **Language:** Kotlin 2.3+ / Modern Android Gradle Plugin (AGP 9.0+)
